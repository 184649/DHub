# DHub 固定バー

## 使い方

管理画面の先頭にある青い **「固定バーを表示」** で、ファイル・フォルダー・URLを直接開く横長のバーを表示します。既存のお気に入りがそのまま固定項目になります。登録全体を勝手にお気に入りにしたり、旧データを自動で取り込んだりはしません。

- 一覧で複数の項目を選んで **「選択をバーに追加」**。まだ固定されていない項目だけ、バーの末尾に追加します。
- バーへファイルやフォルダー、http/https URLをドロップして固定できます。バーの **「＋ 追加」** では起動引数や開くアプリも指定できます。
- 同じ起動先・引数・アプリの登録がある場合は、その登録を固定します。違う引数やアプリを使う登録は別のものとして残します。`.lnk` / `.url` は元ファイル自体を起動する登録として扱います。
- 管理画面への従来のドロップは登録だけです。バーへのドロップと異なり、自動でお気に入りにはしません。
- 各ボタンはワンクリックで起動。右クリックの **「左へ移動」「右へ移動」** で並べ替え、**「バーから外す」** で固定だけ解除します。元の登録やファイルは削除しません。一覧の右クリックからも並べ替えできます。
- 横幅に収まらない項目は **「»」** で開きます。ここでも直接起動でき、右クリックで順序変更できます。
- パスや引数はツールチップにまとめ、名前を短く表示します。同名の登録や省略後の表示が同じ登録には、先頭に番号を付けて区別します。極端に狭い画面では操作部分を折り返します。
- 左端のつまみをドラッグして移動。初回は主画面のタスクバーを除いた作業領域の下端に表示し、移動後の位置を保存します。画面構成が変わった場合は現在の作業領域内に収めます。
- **「×」または Alt+F4 はバーだけを隠します。** 管理画面の「固定バーを表示」で戻せます。DHubを終了する場合はメニューの「終了」を使います。
- 「DHub ▾」→「管理」→ **「固定バーを最前面に表示（今回のみ）」** は利用者が選んだときだけ有効になります。Windowsのタスクバー配置、スタートアップ、セキュリティ設定は変更しません。
- 管理画面の **「フォルダー連携」** から既存のショートカットフォルダーをメニューに表示できます。連携解除でも元ファイルは残ります。

表示・位置・固定順の保存に失敗した場合はその旨を表示します。固定項目の編集は画面上で変更前に戻しますが、一部のファイルへ保存済みの可能性は隠しません。保存状態が不確かな場合は「保存データの確認 / 復旧」で確認してください。バーから起動後の履歴保存に失敗しても、起動要求を再送しません。

## 互換性

設定スキーマ4に任意の `LauncherBarLeft` / `LauncherBarTop`（整数または null）を追加しています。項目の `IsFavorite` と `SortOrder` を引き続き使い、既存の表示設定・起動方法を維持します。古い設定で座標がない場合は初回位置を使います。プレビュー用インポートの厳密なフィールド検証にも追加し、未知のフィールドや不正な型は引き続き拒否します。

## 検証状況と残る確認

Linux の既設 .NET 8 を使い、WPFに依存しないランチャー回帰試験を実行しました。固定順の安定性、左右移動、画面境界・負座標、座標の保存互換性、起動方法の区別、保存失敗時のロールバック、既存の起動履歴・フォルダー参照を対象にしています。

**Windows上でのWPFコンパイル、実際の画面操作、ドロップ、モニター/DPI切り替え、プロファイルインポートのWindows試験は、この変更のLinux確認では実施していません。** ソースの静的検査や純粋関数の合格は、GUI動作の合格を意味しません。

Windows CIでアプリをビルドし、`tests/LauncherRegression` と `tests/ProfileImport.Tests.ps1` を実行した後、隔離したプレビュープロファイルで次を確認してください。

1. 空のプロファイルから、ファイル・フォルダー・URLを追加して各ボタンを一度ずつ起動。
2. 同名・別引数・別アプリ、既存項目の再ドロップ、無効なドロップ、追加ダイアログのキャンセル。
3. 左右の端での移動、8項目を超える固定、オーバーフローからの起動と順序変更。
4. バーを移動・非表示・再表示し、終了・再起動後に同じ順序と位置が戻ること。
5. 主画面と左側の副画面、異なるDPI、画面切断、作業領域変更でバーと操作ボタンが見えること。
6. 編集・解除後に開いていた古いメニューから誤った登録を起動しないこと。
7. 読み取り専用・保存失敗時に登録と順序と選択が保たれ、状態を説明するメッセージが出ること。
8. 最前面表示は明示操作だけで切り替わり、バーの×で常駐は終了せず、「終了」で全ウィンドウが閉じること。
